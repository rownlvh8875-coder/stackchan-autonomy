# 2026-11-20 — 오프라인 ‘조수야’ 비호출어 비교 필터 개발·보정 기록

**상태: 오프라인 실험 / 실기기 적용 거부 / 새 독립 평가 전 개발 데이터 진단**

## 목표와 데이터 구분

이전 실험은 정해진 SWK1 템플릿(3개)으로 ‘조수야’ 감지가 개선됐지만, 유사한 한국어 단어를 과도하게 수락했다. 이번 단계는 **기존 SWK1 프로필과 알고리즘을 그대로 유지**하고, 비호출어 특징까지 비교하는 거부 필터를 오프라인에서 연구한다.

- 기존 등록·보정 WAV에서 **비호출어 10개**를 가져온다.
- 새로 생성한 Heami 합성 비호출어 16개 중 **처음 8개**를 비호출어 참조 특징으로 추가해 총 **18개**의 거부용 특징을 구성한다.
- 나머지 **8개**는 개발용 비호출어 점검에만 사용한다. 기존 보정용 ‘조수야’ 음성 **5개**도 개발 진단에 재사용하며, 각각과 독립된 보류·평가로 주장하지 않는다.
- 앞서 이미 공개·분석한 16개 평가 WAV는 **코드에서 전혀 열지 않는다**. 단, 신규 합성 비호출어의 일부 **표현/단어**는 앞선 공개 평가에서 관찰한 음성적 혼동을 참고하여 선정했다. 따라서 전혀 미지의 발음·화자에 대한 검증이라는 주장은 할 수 없다.
- Microsoft Heami Desktop 동일 목소리만 사용하며 실제 사용자 음성이나 다른 음향 환경을 사용하지 않았다.

## 실험용 판정

`core/offline_contrastive_wake.hpp`은 긍정 SWK1가 수락한 경우에도 비호출어 유사도를 검사하는 **별도 호스트 전용** 알고리즘을 제공한다. 고정한 거부 조건은 다음과 같다.

```text
accept = positive_SWK1_accepts
         AND nearest_nonwake_DTW_distance > 2.0 × nearest_wake_DTW_distance
```

두 점수는 모두 기존 `wake_dtw_distance`를 사용한다. 실패, 음성 파형 형식 오류, 비호출어 특징 부족(10개 미만), 유효하지 않은 프로필, 무음은 거부한다. 템플릿은 최대 48개까지 받을 수 있지만, 이 값에 대한 ESP32-S3 성능과 RAM 사용량은 측정하지 않았다.

비호출어 특징을 포함한 C++ 프로그램 `tools/wake_contrastive_eval.cpp`는 **오프라인 호스트에서만** 구동한다. `app_main`, K151 I2C/I2S/PMIC, 안전용 HOLD, NVS/OTA, 실기기 음성 인식기는 변경하지 않았다. 이 알고리즘은 학습된 한국어 음향 모델이 아니다.

## 보정 데이터에서 관측한 진단 결과

| 합성 음성 조건 | 기존 호출 수락/5 | 비교필터 호출 수락/5 | 기존 비호출어 오인식/8 | 비교필터 오인식/8 |
|---|---:|---:|---:|---:|
| 깨끗한 음성 | 5 | 5 | 1 | **0** |
| 음량 50% | 5 | 5 | 1 | **0** |
| 20dB 명목 SNR 백색소음 | 5 | 5 | 4 | **3** |
| 10dB 명목 SNR 백색소음 | 5 | **4** | 1 | **0** |
| 5dB 명목 SNR 백색소음 | 0 | 0 | 0 | 0 |
| 0dB 명목 SNR 백색소음 | 일괄 거부 | 일괄 거부 | **유효한 건수 없음** | **유효한 건수 없음** |
| 인공 반사음 80ms | 5 | 5 | 1 | **0** |
| 인공 반사음 160ms | 0 | 0 | 0 | 0 |

**판정:** 미검증·실기기 적용 거부. 오인식이 일부 줄었지만, 20dB 조건의 **3/8 오인식**과 10dB 조건의 **1/5 호출 누락**이 남았다. 0dB의 일괄 거부를 오인식 0건이라고 해석해서는 안 된다.

1.125배와 1.5배 거부 기준은 개발 데이터에서 **비호출어 오인식이 감소하지 않아** 제외했다. 보정 데이터의 거리 비율을 분석하면 깨끗한 음성에서 실제 호출 최소 비율 2.864 대 오인식 최대 1.603으로 차이가 있지만, 10dB에서는 실제 호출 최소 비율 1.996 대 오인식 최대 1.968로 간격이 매우 좁다. 20dB 조건에서는 잘못 수락된 비호출어의 비율이 최대 2.624이다. 모든 환경에서 모든 호출을 놓치지 않으며 모든 오인식을 제거하는 **단일 고정 비율을 이 표본만으로 찾을 수 없었다**.

## 고정 후 검증 방법

이 설정은 새 평가용 음성을 만들기 **전에 코드 커밋으로 고정한다**. 새 음성을 시험한다면 개발 단계와 다른 단어·속도의 합성 음성을 만든 다음, 기준 SWK1만 쓰는 결과와 비교 필터를 같은 자료로 한 번에 검증해야 한다. 새 합성 음성도 동일 화자라 실제 환경 성능은 말할 수 없다. 이미 공개했던 첫 번째·두 번째 합성 평가 자료는 다시 새 독립 시험 자료처럼 활용하지 않는다.

지속해서 연구하려면 음향 인식·음소 분별력이 높은 별도 키워드 모델, 다중 화자 녹음, 조용한 환경과 잡음 환경의 비호출어, 실측 false wakes/hour, wake latency, ESP32-S3 CPU/PSRAM 예산과 하드웨어 복구·물리 STOP 검증이 필요하다. **실기기 설치 보류.**
