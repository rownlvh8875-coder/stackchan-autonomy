# 2026-11-20 — 고정된 비호출어 거부 필터의 신규 합성 음성 검증

**판정: 개선 효과 미입증 / 기존 대비 호출 누락 증가 / 실기기 적용 거부**

## 시험 순서와 데이터 누수 관리

비호출어 비교 필터의 설정을 **커밋 `a59e7beaa3df74da5f45a646140f4b8e6336f6ae`**에 먼저 고정했다. 그 후 Windows 로컬의 Microsoft Heami Desktop 합성 음성으로 **새 ‘조수야’ 4개, 새 비호출어 12개**를 생성했다. 검증할 음성 파일과 결과는 사전에 필터의 거리 비율 2.0을 정하는 데 사용하지 않았다.

고정된 기초 SWK1 프로필은 기존 보정 전용 세 템플릿의 2,507바이트 파일이다. 새 필터는 동일 SWK1를 그대로 사용하되, 처음 10개 기존 보정 비호출어와 새 합성 비호출어 8개를 합친 **18개 비호출어 특징**에 대한 거리를 추가로 비교한다. 새 검증 WAV는 이 18개에 포함되지 않는다.

**중요 제한:** 새 파일들도 같은 Windows TTS 음성 엔진에서 생성됐고, 이전 결과를 본 후 어휘를 선정했다. 따라서 독립 화자, 독립 실제 녹음 환경, 일반화된 한국어 인식 성능이 증명된 것이 아니다.

## 새 평가용 음성에 대한 직접 관측값

C++20 기존 `wake_wav_eval.cpp`(실험용 trim 플래그)와 비호출어 거부를 추가한 `wake_contrastive_eval.cpp`를 사용하여 **완전히 동일한** 새 합성 음성 16개에 대해 아래 조건을 비교했다.

| 시험 조건 | SWK1만 호출 감지 /4 | 비교 필터 호출 감지 /4 | SWK1만 비호출어 수락 /12 | 비교 필터 비호출어 수락 /12 |
|---|---:|---:|---:|---:|
| 깨끗한 음성 | 3 | **2** | 0 | 0 |
| 음량 50% | 3 | **2** | 0 | 0 |
| 백색소음 20dB | 4 | 4 | 0 | 0 |
| 백색소음 10dB | 2 | **1** | 0 | 0 |
| 백색소음 5dB | 0 | 0 | 0 | 0 |
| 백색소음 0dB | **일괄 거부: 건수 없음** | **일괄 거부: 건수 없음** | **건수 없음** | **건수 없음** |
| 인공 반사음 80ms | 2 | **0** | 0 | 0 |
| 인공 반사음 160ms | 2 | 2 | 0 | 0 |

**핵심 결론:** 새 비호출어 12개에 대해서 기존 방식부터 잘못 수락한 사례가 없었으므로, 필터의 오인식 감소 효과를 입증할 수 없었다. 오히려 새 필터는 깨끗한 음성에서 호출을 3/4→2/4, 10dB 조건에서 2/4→1/4, 80ms 반사음에서 2/4→0/4로 더 많이 놓쳤다.

사전에 관찰했던 **개발용** 근접 발음 자료에서는 20dB 소음의 오인식 4/8→3/8 등 일부 감소가 있었으나, 이는 보정 데이터 점검이며 새로운 시험에서 일반화된 결과가 아니다. 새 결과를 이용해 필터 비율을 조정하지 않고, **채택 거부**로 기록한다.

## 공개 자료 및 재현

- `fixtures/korean_heami_contrastive_postfreeze_20261120/`: 새 합성 WAV 16개, 전부 `evaluation`만 포함한 JSON 목록, SHA-256 검증 목록.
- `fixtures/korean_heami_hardneg_20261120/`: 오프라인 보정용 신규 한국어 비호출어 16개. 처음 8개만 필터 특징으로 사용; 나머지 8개는 개발 자료.
- `fixtures/korean_heami_fresh_holdout_20261120/robust_trim_aug_frozen.swk1`: 기존 고정된 3템플릿 SWK1 (변경하지 않음).
- `tools/generate_contrastive_postfreeze_holdout.py`: Windows 로컬 SAPI 합성 절차.
- `tools/evaluate_contrastive_postfreeze.py`: 이미 고정된 프로필·비호출어 근거로 실제 C++ 오프라인 프로그램을 호출해 전후 비교.
- `tests/test_contrastive_postfreeze.py`: 공개 합성 파일 SHA-256과 C++ 검증 경로 확인.
