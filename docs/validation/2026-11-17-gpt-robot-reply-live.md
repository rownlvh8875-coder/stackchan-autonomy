# GPT API 답변 → 로봇 음성 현장 확인 — PASS

확인 접수일: **2026-11-17 (한국 시간)**.
근거: 사용자의 노트북 설정·실행 후 정상 음성 응답 보고와 GPT 성공 표시 확인.
클라우드에서 사용자 키나 실제 접속주소로 API/장치에 접속해 시험한 결과는 아니다.

## 실행 경로와 근거

- 안내한 배포 버전: `feat/transport-soak`의 `ccd2978`.
  실행 시점의 SHA를 사용자 명령 출력으로 별도 수집하지는 않았다.
- 사용자는 노트북 `.env` 저장 완료 후, 안내한 업데이트와
  `stackchan-pc-mcp --gpt` 실행 순서에 대해 로봇 답변이 정상이라고 보고했다.
- 이어 현재 cmd의 `PC_GPT_ANSWERED=1` 또는 다른 번호의 성공 표시가 있는지 확인했으며,
  사용자는 **“ANSWERED 표시도 있음”**이라고 답했다. 새 API 질문을 추가로 요구하지 않았다.
- 정확한 호출 번호, 전체 CLI 원문, 실제 모델 ID, API 응답 ID와 발화 원문/음성 파일은
  별도로 제공되지 않았다. 설정 안내의 모델 예시를 관찰한 실제 모델 ID로 단정하지 않는다.
- 직전 장치 확인은 K151·출고 펌웨어/공식 앱 경로다. 이번에 버전을 다시 조회하지는 않았다.

## 판정

| 항목 | 확인 결과 |
|---|---|
| 노트북 로컬 설정 | 사용자 저장 완료 보고 |
| GPT API 성공 반환 | PASS: `PC_GPT_ANSWERED=N` 표시가 있음을 사용자 확인 |
| 로봇 음성 응답 | PASS: 사용자가 질문에 대한 답변이 정상이라고 확인 |
| 현장 확인 방식 | 사용자 보고; 클라우드의 직접 API/장치 측정 아님 |

검증된 프로그램에서 ANSWERED는 실제 Responses API 응답의 완료·허용 블록·JSON 답변을
검증한 뒤에만 출력된다. 따라서 이번 확인은 단순 도구 등록이나 공식 AI의 자체 답변만으로
판정한 것이 아니다. 정확한 비용/토큰 수, 모든 모델 권한, 발화의 글자 단위 일치는 미측정이다.

**공식 음성 서비스 → PC GPT API 답변 → 공식 음성 재생 경로의 현장 PASS.**

공식 서비스가 음성 인식·도구 선택·재생을 계속 담당한다. 이 API 대화는 Codex/ChatGPT의
현재 채팅과 별도이며, 모든 발화의 강제 GPT 라우팅이나 독립 음성 backend 교체는 포함하지 않는다.
직접 모터·STOP·카메라 제어, 장시간 연결·실물24시간 운용의 PASS로 확대하지 않는다.
키·접속주소·계정/장치 식별자·대화 원문은 기록하지 않는다.

실행 방법은 [GPT 연결 설명서](../GPT_ROBOT.ko.md), 자동 검증과 현장 상태는
[검증 JSON](2026-11-17-gpt-robot-reply.json)에 보관한다.
