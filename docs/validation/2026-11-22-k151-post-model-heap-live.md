## 모델 상주 구간

기존 모델 로드가 끝난 시점부터 최대 질문 버퍼, 메모리 BIO TLS 1.2,
합성 JSON과 TTS 응답 디코딩 구간을 측정했다. 수치는 바이트 단위다.

| 메모리 | 시작 여유 | SDK 최저 여유 | 차이 |
|---|---:|---:|---:|
| 내부 8비트 메모리 | 353,659 | 298,695 | 54,964 |
| PSRAM | 8,047,576 | 5,723,848 | 2,323,728 |

합성 응답 본문과 디코딩 PCM이 모두 살아 있을 때 최대 연속 블록은
내부 196,608바이트, PSRAM 5,636,096바이트였다. 질문 384,000바이트,
TTS 본문 960,000바이트와 디코딩 PCM 960,000바이트의 PSRAM 배치를
관측했다. 별도 합성 JSON 응답은 262,144바이트였으며 같은 측정 구간의
앞 단계에서 디코딩했다.

ESP-IDF는 해당 영역별 최저값을 합산한다. 위 차이는 그 집계의 변화이며,
Wi-Fi·소켓·실제 서버가 포함된 운영 경로의 최고 사용량은 별도로 측정해야
한다. 실물 마이크·스피커가 활성화된 상태의 headroom도 아직 확인하지
않았다. `operating_admission:false`였다.
[ESP-IDF 힙 지표](https://github.com/espressif/esp-idf/blob/fff9895c82d744c7237be8847347bdd1b07c6643/components/heap/include/esp_heap_caps.h#L205)

수집기는 USB reset 값 11, START 1회, 두 모델 reset과 공통 입력의
11개 계측 지점, 24kHz 합성 32프레임 완료, 최종 HOLD를 4.8285초에
관측했다. 합성 직결 64개 chunk의 최대 추론은 7.188ms, 공통 입력 최대
poll은 계측 포함 9.003ms였다. 합성 감지와 STOP 전송은 각각 0회였다.
실제 음성 수집·전송과 유료 API도 0회다. 실제 “Hi StackChan”, 물리
STOP 및 독립 GPT 대화는 아직 검증하지 않았다.
