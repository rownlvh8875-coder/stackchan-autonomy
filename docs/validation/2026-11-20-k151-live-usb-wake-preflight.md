# K151 실기기 USB·음성 경로 점검 (2026-11-20, 한국 시간)

## 범위 및 결론

**실행 범위: 기존 출고 펌웨어 변경 없는 현장 PC의 USB 수신·백업 무결성·노트북 마이크 레벨 점검.**
실물 K151 USB 연결과 시리얼 수신은 확인했다. 그러나 이 연결만으로 **K151 내장 마이크의 “조수” 호출어 인식**, 새로운 독립형 GPT 대화 경로 또는 USB 음성 스트리밍이 동작함을 입증하지 못했다. USB/펌웨어의 읽기 전용 점검을 근거로 플래시 설치 제한을 풀지 않는다.

### 프라이버시·안전 조치

- 로봇 USB에는 읽기 용도로만 포트를 열었으며 송신 바이트는 0. 칩 리셋·부트로더 진입·SPI flash 읽기/쓰기/erase·OTA·NVS 변경·모터/카메라/스피커 명령을 실행하지 않았다.
- 로봇 시리얼 원문과 노트북 마이크 PCM은 로그/파일/외부 서비스에 저장하지 않았다. 마이크 레벨 집계치만 보고했다.
- 사용자 계정 토큰, NVS, 로컬 원본 flash 바이너리, 장치 MAC 또는 프라이빗 대화 내용은 공개하지 않는다.
- 포트 열기/제어선 설정이 장치 회로에서 어떤 신호로 해석됐는지는 별도 계측하지 않았다. **명시적인 리셋을 요청하지 않았음**과 **전기적 무영향 입증**은 구별한다.
- PowerShell ps1 스크립트 실행은 Windows 실행 정책으로 거부되어 실행하지 않았다. 보안 정책을 변경하지 않았고, 정상 대화형 명령으로 짧은 COM3 수신을 확인했다.

## 음성 호출어의 현 단계

- GitHub 브랜치 feat/wakeword-josu의 새 학습/합성 음성 24개, SWK1 프로필, PC 2차 전사 기본값은 **“조수”**다.
- 이 프로필의 TTS 합성 평가 결과는 호출 **2/2 수락**, 비호출 **0/6 수락**(“조수야” 포함)이다. 이 숫자는 실사용 음성 정확도가 아니다.
- firmware/standalone/esp_app/main/app_main.cpp는 compile-only HOLD: 실제 마이크, 모터, 네트워크 및 보이스 서비스를 기기에서 시작하지 않는다.
- 출고 K151의 USB Serial/JTAG 포트에 접속했다고 SCOB 관찰 프로토콜이나 새 wake listener가 자동 설치되지는 않는다.
- 즉, **USB 통신 테스트 PASS ≠ K151 내장 마이크 기반 “조수” 호출 PASS**. 현재 수집 정보로는 출고 펌웨어에서 PC로 실제 내장 마이크 PCM을 읽는 지원 경로가 확인되지 않았다.

## CI 회귀 진단

기존 PR #3에서 2026-11-20 Linux CI의 새 fixture 무결성 검사가 실패했다. 원인은 synthetic-sapi.wake-corpus.json의 Windows 로컬 CRLF 파일에 대해 기록한 SHA-256과 Git의 LF 변환 후 Linux checkout 파일 해시가 달라진 것. SHA256SUMS.txt를 커밋된 LF 바이트 기준으로 갱신하고 해당 manifest를 .gitattributes에서 -text로 지정해 신규 checkout의 바이트 보존을 명시했다. 실제 Linux CI 재검증 결과는 workflow 완료 후에만 PASS로 기록한다.

## 실기기 완료를 위한 다음 검증 기준

1. 제조사 출고 앱의 **MicTest**를 기기 화면에서 수동 실행하고, 소리 입력·중지·물리 이상 여부를 확인한다. 이는 제조사 입력 회로 시험이지 “조수” 호출 성공이 아니다.
2. 새 SWK1 프로필을 K151에 적용하려면 출고 기능/계정 인증을 유지하는 공식 지원 경로 또는 명시 승인된 별도 개발 이미지가 있어야 한다. 현재 그런 **실행 가능한 경로는 확인하지 못함**.
3. K151 내장 마이크 원시 PCM을 얻는 **지원·검증된 인터페이스**, 스피커 에코 억제, 정지/재부팅/원본 복구 경로를 먼저 마련한다. USB만 연결하고 고정 주소에 임의 패킷을 보내지 않는다.
4. 실화자 발화(“조수”)와 유사어(“조수야”, “조수님”, “조수석” 등), 거리/소음/스피커 재생 시 오탐률·미탐률을 새 데이터로 측정한다. 음성 자료 공개 여부와 개인정보 보관 정책을 별도로 결정한다.
5. 등록 성공 전 HOLD를 유지한다. **펌웨어 설치·모터 시험은 이번 작업에 포함하지 않았다.**
