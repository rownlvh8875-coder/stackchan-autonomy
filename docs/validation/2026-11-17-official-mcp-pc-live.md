# 공식 AI → PC 도구 현장 검증 — PASS

확인 접수일: **2026-11-17 (한국 시간)**.
사용자가 Windows 노트북과 실제 K151에서 수행한 결과를 제공하고 음성 일치를 확인했다.
클라우드에서 장치나 사용자 접속주소에 연결해 측정한 결과는 아니다.

## 시험 대상과 근거

- 사용자가 직전에 업데이트한 체크아웃: `feat/transport-soak`, `83a8cde`.
- 실행 명령: 기존 체크아웃에서 `uv run --frozen stackchan-pc-mcp`.
- 직전 기록의 기기/앱: K151, 본체 V1.6.2, StackChan World v1.2.12.
  이번 확인에서 버전을 별도로 다시 조회하지는 않았다.
- 출고 펌웨어와 공식 앱을 유지하는 외부 MCP 도구 확장 경로다.
- 토큰·접속주소·기기 식별자·계정·원본 대화/매체는 이 기록에 포함하지 않는다.

## 확인 결과

| 확인 항목 | 결과 / 근거 |
|---|---|
| 외부 MCP 연결 | PASS: 사용자가 제공한 CLI 출력에 OFFICIAL_MCP_CONNECTED |
| MCP 초기화 | PASS: OFFICIAL_MCP_INITIALIZED |
| 도구 목록 요청·응답 | PASS: OFFICIAL_MCP_TOOLS_LISTED |
| 이번 실행의 진단 코드 | 293386; 인증 비밀이 아니며 다음 실행에서는 달라짐 |
| 실제 PC 도구 호출 | PASS: PC_TOOL_CALLED 표시 또는 호출 횟수 증가를 사용자 확인 |
| 로봇의 음성 응답 | PASS: 로봇이 같은 코드293386을 읽어 줬음을 사용자 확인 |

사용자는 실제 호출과 음성 코드 일치 두 기준을 모두 확인했다고 답했다.
새 호출 이후의 전체 CLI 원문과 정확한 최종 호출 횟수는 별도 제공되지 않았다.
공식 앱 목록 화면의 별도 사진도 없으므로 앱 UI의 표시 모양을 판정하지 않는다.
기능 등록과 실제 사용은 위 도구 호출·일치 코드로 확인했다.

**판정: 공식 AI → PC 연결 확인 도구 → 로봇 음성 응답 경로의 현장 PASS.**

## 이 결과에 포함하지 않는 범위

- PC OpenAI 자율 엔진의 직접 로봇 제어, AI/음성 backend 교체.
- 우리 앱의 실제 자세·터치 조회, 서보/LED/표정 명령, 물리 STOP·단절 시험.
- 우리 카메라·마이크·STT/TTS 어댑터, 파일/명령 실행 기능.
- PC 도구의 장시간 연결·재시작 복구, 실물 연속24시간 운영.

이번 한 번의 공식 음성 상호작용을 위 미실행 항목의 PASS로 옮기지 않는다.
