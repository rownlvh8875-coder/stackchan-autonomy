# “조수” 실제 사용자 마이크 진단·등록 변경 설계

사용자가 제공한 2026-11-20 작업 지시서를 구현 범위로 사용한다. 기준은 PR #3 / `feat/wakeword-josu` / e8ee330이다. 기존 미완료 브랜치 변경은 가져오지 않는다.

목표는 실제 노트북 발화의 `UNVERIFIED_NO_MATCH`를 입력 품질, VAD/구간, MFCC/DTW 거리로 나누어 진단하고 사용자별 SWK1을 등록·보정·독립 평가할 수 있게 하는 것이다. 22,080프레임만으로 잘림이나 발화 내용을 단정하지 않는다. 마이크·개인 음성은 이 클라우드에서 접근할 수 없으므로 원인 확정과 사람 인식률은 현장 실행 전까지 미검증이다.

선택: 기존 C++20 MFCC/DTW와 SWK1을 유지하고 동일한 PC 전처리를 등록과 평가에 적용한다. TTS 임계값을 올리는 방식은 사용자의 오탐 방지 조건에 어긋난다. Whisper/Vosk PC 2차 모델은 기존 실험으로 남기며 ESP32-S3 단독 인식의 대안으로 오인하지 않는다. 새로운 신경망 학습은 실제 사용자 자료가 없는 현재 단계의 우선 작업이 아니다.

## 변경 계약

- 명시적 `--listen`/`--enroll`과 입력 장치 선택으로만 최대 3초씩 녹음한다. 장치 목록 및 매 녹음 전 장치 identity를 재확인한다. 원본 PCM/WAV는 메모리에서만 처리하고 파일 저장·네트워크·API·로봇 출력은 없다.
- 진단: 입력 형식/길이, RMS/peak/clipping, 음성 시작·종료와 추출 경계/여유, capture-edge 위험, FIR 출력 길이, 실제 DTW 최솟값·임계값·여유, 처리시간. 경계 위험을 실제 잘림으로 단정하지 않는다. 무음·클리핑·경계 위험 등록 샘플은 거부한다.
- C++의 기존 기본 판정 출력은 호환 유지. 추가 bounded stdin 모드에서 특징 추출·SWK1 보정·메모리 프로필 점수를 제공한다. 특징/프로필은 Python과 C++ 사이의 로컬 pipe로만 전달하며 콘솔에 출력하지 않는다.
- 등록 3회, 보정 호출 5회/비호출 10회로 프로필을 고정한다. 이후 새 호출 5회/비호출 10회를 수집해 독립 평가한다. 유사어 “조수야/조수님/조수석/주스/주소” 포함. 데이터 중복을 거부하며 평가 실패를 학습에 재사용하거나 임계값 조정하지 않는다.
- 사용자별 프로필은 명시된 새 `.local/` 파일에만 저장한다. 원본/특징/평가음성은 저장하지 않는다. 평가 성공은 이 소규모 PC 세션에서의 관측이며 실물 K151 정확도나 통계적 인식률이 아니다.
- 기존 Heami 프로필과 평가 수치를 함께 표시한다. 프로필 파일과 음성 모두 Git 업로드 금지. 진단 JSON은 음성·특징·경로·장치 이름·키를 포함하지 않는다.
- 기존 `WakeVoiceEntry`의 동의/STOP/재생 중 차단 및 Mock 음성 흐름을 보존한다. 펌웨어·NVS·OTA·모터·실제 API는 이번 변경 대상이 아니다.

## 검증

실제 C++20 바이너리, 합성 fixture와 결정적 수학 신호로 stdin 경계·거부·SWK1 호환·FIR 주파수응답/길이·VAD 경계·품질·등록 분리를 검사한다. 기존 공개 Heami 평가 2/2 및 비호출 0/6을 보존한다. 실제 노트북 소리, 거리/소음/억양/무발화 오탐, 메모리 장시간 관측은 사용자 현장 검증으로 구분한다. Linux/Windows PC 검사를 CI에 넣으며 ESP32 compile-only HOLD를 유지한다.
